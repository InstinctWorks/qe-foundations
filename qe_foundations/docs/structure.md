# QE Foundations — Repository Structure

## Overview

This repository contains reusable Python utilities and serves as the foundation for Revature's QE Foundations exercises.

## Directory Structure

| Directory | Purpose | Week 2 Schedule |
|---|---|---|
| `qe_foundations/` | Main Python package containing reusable functionality. | Monday |
| `qe_foundations/utils/` | String, number, date, and test-data generation utilities. | Monday |
| `qe_foundations/ingestion/` | CSV, JSON, and XML ingestion and validation. | Tuesday |
| `tests/` | Automated tests using PyTest. | Wednesday onward |
| `data/` | Sample input files and test data. | Tuesday |
| `docs/` | Project documentation and reflection notes. | Monday onward |
| `sql/` | SQL validation queries and joins. | Thursday–Friday |

## Weekly Development Plan

- **Monday:** Repository setup, virtual environment, Python utilities, and dependency management.
- **Tuesday:** Data ingestion, custom exceptions, and file processing.
- **Wednesday:** Logging and automated unit testing.
- **Thursday:** SQL data-validation queries.
- **Friday:** SQL joins and integration testing.

The repository will be expanded throughout Week 2 as new functionality is implemented.
